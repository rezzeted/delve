# Delve: библиотека ассетов v1 (D1.2)

Шесть ассетов слотов (`assets/`, контракты — `slots_v1.md` §2) + две библиотеки.
Проверка: `delve_assets_test` (R-A4: каждый ассет из своей фикстуры — без
E-диагностик, меш непуст, точное число якорей; паритет кодов `codes.pgg` ↔
`delve/project.h`).

## Библиотеки

- `codes.pgg` — `ST_*`/`RL_*`/`DR_*`/`DT_*`/`AK_*`/`ZP_*` def-константы
  + палитры `style_color`/`style_color_mortar` (неизвестный код — маджента,
  fail-loud). Значения нормативны (§1 слотов).
- `patterns.pgg` — `zone_style` (встык/штраба, слоты §3) + общий `elem_zone`:
  правило целого элемента (единогласные углы с отступом 1e-4, иначе пропуск;
  вне полосы зоны — стиль юнита, без экстраполяции).

## Ассеты и их пределы v1

- `rooms/fill_v1.pgg` — пол + плоский потолок боксами по bbox контура.
  ТОЛЬКО прямоугольники (`expect`, иначе ошибка); свет всегда, спавн только залу.
  Свод — не v1.
- `walls/body_v1.pgg` — растворный брус между гранями столбов, проёмы вырезаны
  `clip`, над проёмом перемычка. Высота = max(h_a, h_b) (R-A2).
- `walls/facing_v1.pgg` — ряды отделки: элемент 2×module, толщина 0.05, running
  bond со случайным направлением (`rng`), проёмы вырезаны, зоны через `elem_zone`.
  Элементы НЕ режутся: поперёк границы — пропуск (место закрывает раствор тела).
  Элементы выступают в сторону комнаты (локальный −Z при сегменте по обходу —
  поправка D2.3b: до неё выступали наружу, на дальнюю сторону стены).
- `walls/node_v1.pgg` — столб + ряды по 2 элемента вширь на открытых гранях
  (грань уже 4×module — ряды всё равно кладутся, свес допустим). Локальная ось
  грани: `l = 0` в центре, `+l` направо от нормали; паритет с `+s` несёт `@flip`.
- `doors/opening_v1.pgg` — косяки/балка/порог/полотно; gate = + решётка.
  Решётка смещена к одной стороне полотна, планки и хомут — разной глубины,
  хомут не доходит до кромок полотна: ни одна пара граней не копланарна
  (поправка D2.3b, регресс `GateAssetHasNoDoubleGeometry`).
  Фиксированная нейтральная палитра (стиля нет, колонки `@style` нет).
- `decor/lamp_v1.pgg` — прибор вдоль нормали монтажа + РОВНО 1 якорь света
  (`range = 6.0`).

## Меш и якоря

- Точки меша: `@style: int` (код `ST_*`; у двери колонки нет — сборка даёт 0)
  + `@Cd: vec3` (превью; раствор — приглушённый вариант стиля).
- Якоря: `@kind`/`@dir`/`@range` (§1 слотов); `@label` ставит Delve при сборке
  (PGG `set` не пишет строки, E204).

## Фикстуры (R-A4, слоты §5)

Рядом с ассетом: `<stem>.fixture.json` (`{"params": {...}}`, значения —
param-text, `@path` относительно каталога фикстуры) + `*.points.json`
(`pgg-points/1`). Тест повторяет биндинги PggTool 1:1 (`parseParamText`).
