# Delve: превью F9 v1 (DelveViewer)

`src/apps/DelveViewer`: приложение превью уровня (requirements §7, F9) — 3D-вид
и вид сверху с наложением IR поверх наполненного уровня, плюс read-only
вкладка **Topo** — топология level-synth: 2D-план раскладки и граф переходов
по GUI-free модели `delve::TopoModel` (N4). Своя логика только в приложении
(N4): библиотеки `delve*` не трогает, рендер — `pgg_preview` (оффскрин sokol
+ орбит-камера), панели и оверлей — Dear ImGui. Тест: smoke-прогон в ctest
(`DelveViewer_smoke_layout`).

## CLI

```
DelveViewer [project.json] [--smoke]
```

Быстрый старт: `DelveViewer projects/demo/project.json` — демо-подземелье из
репозитория (L-зал, ворота, переходы камень|кирпич; см.
`projects/demo/README.md`).

- Без аргументов: окно с пустым состоянием; проект открывается из панели
  (поле пути + список недавних за сессию) или drag-and-drop project.json на
  окно. Кнопка **Generate** неактивна, пока поле проекта пустое; ошибка
  загрузки — красным текстом в той же панели. У поля — кнопка «Browse…»:
  модальный файловый диалог на чистом ImGui (`filedialog.h`, без нативных
  зависимостей): текущий каталог + Up, сначала каталоги (`[dir] …`, клик —
  войти), затем *.json (клик — выбрать, двойной клик — принять),
  редактируемое поле полного пути (Enter = Select), Select/Cancel, Esc
  закрывает; старт — каталог последнего выбранного файла, иначе
  `<корень>/projects`, иначе cwd (память на сессию). Выбор в диалоге лишь
  заполняет поле — загрузка по Generate. Относительные пути из панели ищутся
  сначала от cwd, затем от каталога последнего открытого проекта.
- Drag-and-drop (где платформа позволяет; на X11 — через Xdnd): дроп
  project.json открывает его, заменяя текущий уровень. Дроп замороженного IR
  (снифф по подстроке `"delve-ir/` в голове файла) отклоняется с ошибкой:
  вьювер IR не открывает, раскладка всегда генерируется из layout-яруса
  проекта (`build_catalog` → `LayoutGenerator`, attempts=4 →
  `build_ir_from_layout`). Замороженный IR (F5) — вход DelveCli.
- `--smoke`: тот же путь данных без окна и sokol (покрытие в ctest без GPU):
  одна строка статистики в stdout, exit 0; без проекта — usage + exit 2.
- Коды выхода: 0 — ок, 1 — ошибка данных (проект/fill), 2 — ошибка командной
  строки.

Наполнение — `fill_level` с живым `UnitCache` (F8), активы Delve ищутся по
`assets/codes.pgg`: `./assets` от cwd, затем вверх от каталога исполняемого
файла, затем вверх от каталога проекта; слоты проекта дополнительно
отваливаются в `FillOpts::delve_assets` (порядок корней — fill_v1).

## Панели

- **Сайд-панель**: секция проекта и статистика последнего fill (юниты,
  reused/reran, мс, размер кэша), кнопки операций, секции Selection / Units /
  Log. В пустом состоянии уровня активна только панель генерации (поле пути
  проекта, недавние, Generate; ошибка загрузки — красным тут же) и Log; после
  загрузки панель складывается в CollapsingHeader «Project: <имя файла>» с
  кнопкой Close (уровень и кэш сбрасываются, превью очищаются) и блоком
  «another project».
- **Виды 3D и Top** — вкладки одного окна справа от сайд-панели (область не
  делится пополам); активна по умолчанию **3D**, оффскрин-рендер идёт только
  у активной вкладки.
- **3D**: level-меш целиком (vertex colors из `@Cd`), орбита/pan/zoom мышью,
  Fit. Здесь же живут подсветка и соло юнита.
- **Top**: второй `GeometryPreview` в проекции `OrthoTop` (+X вправо, +Z вниз,
  §5.1) с тем же мешем; поверх — оверлей ImGui draw list через проекцию
  `viewProj` топ-превью. Слои-чекбоксы: контуры+id комнат, двери (зелёные
  open, оранжевые прочие dtype), владельцы стен, владельцы узлов, якоря
  (ромбики; `@label` — при наведении). Дефолт: комнаты/двери/якоря включены,
  владельцы выключены. Выделение рисуется отдельным ярким проходом независимо
  от слоёв.
- **Topo** — вкладка поверх `delve::TopoModel` (проекция графа + раскладка,
  `src/libs/delve/topo`), две бок-о-бок панели с независимыми камерами,
  порядок всех списков детерминирован (N6). Панель **Plan** — 2D-план в
  клетках world grid (ярус раскладки, не метры): контуры комнат/коридоров
  (без заливки — L-комнаты не выпуклые), отрезки дверей на общих рёбрах
  (зелёные open, оранжевые прочие dtype), id и роль в центроиде; слои
  rooms/ids/doors/roles. Панель **Graph** — граф переходов в стиле
  GraphCanvas PggViewer: боксы узлов 88×36 pt в центроидах комнат (id + роль,
  заливка и обводка цветом роли), bezier-провода узел→узел цветом dtype,
  метка dtype на середине (тёмная плашка), фон `#181b20`; комнаты графа без
  раскладки не рисуются, список «unplaced: …» — под холстом. Обе панели:
  pan (drag ЛКМ/ПКМ/СКМ), zoom к курсору (колесо), Fit (автофит по контурам /
  по боксам), клик по комнате — выделение (общее с инфо-панелью), клик по
  пустому месту — сброс, двойной клик — фокус камеры панели на bbox комнаты.
- **Инфо-панель** (секция Selection, приёмка F9): клик ЛКМ по топ-вкладке
  (без drag'а) выбирает комнату (point-in-polygon), стену/дверь (< 0.5 м до
  отрезка) или узел (< 0.5 м). Показывает параметры объекта и происхождение
  каждого значения цепочкой F12 (`format_prov`): у комнаты h/style/floor/ceil/
  wall_t, у двери dtype/h/frame/thick; у стены — владелец/стороны/двери, у
  узла — владелец/грани. Кнопки: Focus (камера обоих превью на bbox объекта),
  Highlight unit, Solo unit.
- **Панель юнитов** (секция Units): `FillResult.units` группами по слоту,
  действия над выбранным — Focus (bbox точек спана), Highlight (временная
  points-группа на копии меша + `highlightGroup`, только 3D), Solo (под-меш
  спана через `topo::deleteByMask` с инвертированной маской, только 3D;
  «Back to level» возвращает уровень).
- **Log**: последние записи fill — юнитов, точек меша, мс, reused/reran;
  ошибки операций — красным.

## Операции

- **Refill (reload project)**: перечитывает проект с диска, пересобирает IR
  из того же `LayoutData` и наполняет через тот же `UnitCache` — в логе видно
  reused/reran (F8, D3). Камера сохраняется.
- **Re-layout**: generate заново (тот же seed, attempts=4) → новый
  `LayoutData` → IR → refill; неизменённые юниты приходят из кэша (приёмка
  D3). Камера перефокусируется на сцену.
- Обе операции сбрасывают выделение и выбор юнита (id/спаны пересобираются).

## Лимиты v1

- Пикинг только в топ-вкладке; в 3D-виде выбора нет.
- Topo — только просмотр: редактирования нет (drag-узлов, записи в проект);
  позиции узлов графа = центроиды раскладки, force-directed раскладки боксов
  нет — на плотных уровнях боксы в фит-зуме перекрываются, зум вперёд их
  разводит (размер боксов фиксирован в пикселях).
- Якоря — только в оверлее топ-вкладки (в 3D-рендере не рисуются).
- Замороженный IR не открывается — раскладка всегда генерируется из проекта
  (чтение delve-ir/* остаётся в DelveCli).
- Раскладка синхронна (малого уровня — быстрая); отмены из UI нет
  (F3-хук `request_cancel` в библиотеке есть, асинхронность — позже).

## Тесты

- `DelveViewer_smoke_layout`: `--smoke src/apps/DelveViewer/smoke_project.json`
  (генерация раскладки → IR → fill). Свой фикстурный проект, потому что
  `src/tests/data/d2_project.json` IR построить не может: роль corridor в нём
  переопределяет wall_t, и общие стены коридора с комнатами дают конфликт
  толщин — ошибку F4 по 5.2 (by design).
