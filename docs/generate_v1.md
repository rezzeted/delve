# Delve: вызов раскладки v1 (D2, F3)

`src/libs/delve_layout/generate.{h,cpp}`: проект v1 + каталог → вызов
edgar (`GraphBasedGeneratorGrid2D`) с сидом, бюджетами, отменой и
повторными попытками; сериализация результата в `delve-layout/0`
(`src/libs/delve/layout.{h,cpp}`: `LayoutData`, `read_layout_json`).

## Отображение на edgar

- Комнаты графа нумеруются по порядку объявления (`index_to_id`);
  рёбра графа — соединения edgar; роль `corridor` — коридорная комната
  второй стадии (C# `CorridorRoomDescription` всегда stage 2).
- `min_room_distance` проекта — поле уровня edgar (штраф только для
  пар без общего ребра: соединённые дверью комнаты обязаны касаться).
- Шаблоны и описания комнат — из каталога (`docs/catalog_v1.md`).
- Двери вычисляются проходом `compute_layout_doors` со своим сидом
  (`seed + 0x9e37`, детерминирован): порт возвращает позиции комнат,
  двери — отдельным шагом.

## Сид, бюджеты, попытки (R-G4)

- Попытка `k` использует `layout_seed + k` (`layout_seed` — младшие
  31 бит сплита сида проекта, `docs/project_v1.md`).
- `time_budget_ms` / `iteration_budget` — ранняя остановка порта
  (`early_stop_*`); нулевой бюджет честно даёт «не разложилось», а не
  зависание. Без бюджетов прогон идёт до первой валидной раскладки.
- Исчерпание попыток — ошибка с диагностикой: число комнат и рёбер,
  базовый сид, бюджеты и причина отбраковки последней попытки
  (комнаты/двери/пересечения/дистанция).

## Валидность результата

Раскладка годна, если: комнат столько же, сколько в графе, и каждая
ровно раз; у каждого ребра графа есть дверь с обеих сторон с общим
мировым отрезком; контуры не пересекаются по площади (касание рёбер
обязательно); пары без общего ребра разведены не ближе
`min_room_distance` (манхэттенский зазор боксов — та же метрика, что в
порте). Дистанция перепроверяется на своей стороне, итог не зависит
от внутренней энергии порта.

## Отмена

`request_cancel` потокобезопасна и липкая до `reset_cancel`: отмена до
старта и между попытками возвращает «cancelled»; во время прогона без
бюджетов прерывает генератор порта. С бюджетами отмена порта —
no-op (ограничение порта: отмена и ранняя остановка взаимоисключающи),
действует только проверка между попытками. Один `generate()` на
экземпляр одновременно.

## Формат `delve-layout/0`

Стабильные ключи (N6): `format`, `source{project, seed}`,
`rooms[]` по возрастанию `id`: `id`, `role`, `template`, `corridor`,
`grid` (контур в клетках edgar, `area2 < 0`), `doors[]` по
`(to, g0, g1)`: `to` (id соседа), `grid` (отрезок, лексически меньшая
точка первой). Тип двери здесь не хранится — он берётся из ребра
графа проекта при построении IR (`build_ir_from_layout`, D2.3b, F4 v2).

## Поведенческие тесты (§9.1)

- Длина двери из проекта доходит до раскладки (`d2_doors.json`,
  `door_length: 2` — отрезок длиной 2 клетки с обеих сторон ребра).
- Мин-дистанция держится на несоседях цепочки (`d2_project.json`:
  пара entry–hall при `min_room_distance` 1 и 2). На деревьях жадная
  раскладка всегда разводит комнаты, поэтому демонстрации эффекта
  ручки (`0` против `N`) на быстрых фикстурах нет — тест фиксирует
  сквозной контракт (валидные раскладки удовлетворяют дистанции).
