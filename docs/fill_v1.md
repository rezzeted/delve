# Delve: наполнение F6 v1 (D1.3)

`src/libs/delve_fill`: R-A3 (`check_asset`) + `fill_level` (IR → юниты → прогоны
PGG → сборка). Тесты: `delve_fill_test` (8 шт.).

## Локальные кадры (R-A9, мировых координат во входе нет)

| Юнит | Начало | Ось +X | Сборка |
|---|---|---|---|
| `room:*` | min-угол bbox контура | +X мира | перенос |
| `wall:*` | конец оси (lex-min) + `t_end0/2` | вдоль оси | yaw + перенос |
| `fac:*` | `seg.from` | вдоль обхода | yaw + перенос; `n` → `(0,0,±1)` |
| `node:*` | вершина сетки | оси мира | перенос (без поворота) |
| `door:*` | конец чистого проёма (lex-min) | вдоль проёма | yaw + перенос |
| `deco:lamp:*` | точка монтажа | оси мира | перенос (стена — тоже: normalizr нет, `n` входная) |

Тело стены идёт между гранями столбов: отступы на концах — по `thick_ends`
стены (поправка D2.3b: была единая `thick` — та же величина при единой
толщине).

Поворот — рыскание `atan2(−dz, dx)` (конвенция PGG проверена зондом: `+90°`
переводит `+X` в `−Z`); сборка — `R`, затем `+t`, как один `transform`.
Эквивалентность «кадр + сборка = мировой прогон» проверяет тест
`RotatedFrameEquivalence` (вертикальная облицовка с зоной: расхождение < 1e-4 +
побайтово `@style`).

## Сиды (поправка D2.3b)

Проекты `delve-project/1` наполняются от сплит-сида `fill_seed_v1(seed)`
(project_v1 §Сиды); путь v0 использует сырой seed проекта (совместимость).
`unit_seed` юнита — от выбранного fill-сида, как в slots §1. До D2.3b
наполнение всегда бралось от сырого seed — сплит применялся только раскладкой.

## Лампы (размещение считает Delve)

По комнате (id по возрастанию): центрированная сетка `nx × nz`,
`nx = max(1, round(sx / lamp_step))` (то же по `z`), монтаж на плоскости
потолка, `n = (0,−1,0)`, стиль = стиль потолка. `k` в `deco:lamp:<k>` —
сквозной по уровню (поправка слотов D1.3). Позиции вне контура фигурной
комнаты пропускаются (point-in-polygon; на прямоугольниках не срабатывает —
поправка D2.3b). Настенных ламп F6 v1 не ставит
(ассет их умеет — покрыто вариантом `AssetVariants`).

## Сборка

- Меши юнитов — конкатенацией (топология со сдвигами, колонки объединением
  с нейтральным заполнением; `door` без `@style` получает `0`, §1 слотов).
- Якоря + `@label: string` = `<unit_id>#light|spawn|poi` (вид из `@kind`;
  неизвестный вид — ошибка `delve/run`).
- Порядок детерминирован (юниты по видам и id); повторы побитово совпадают
  (`FillDeterministic`, любые потоки PGG).

## R-A3 v1: границы

- Имена/типы `param` (включая `geo`-kind), дефолты скаляров (§5/R-A4),
  имена выходов, `slot_version() == 1` (docstring — не оператор, разрешён).
- Geo-kind выходов (`mesh`/`points`) PGG статически не отдаёт — проверяется
  при первом прогоне юнита (поправка слотов §4 D1.3).
- PGG-диагностики статической стадии цитируются как есть (`E103`, …).

## Замер N5 (слоты §0)

Уровень frosted `tutorial_corridors` (17 комнат, ~280 юнитов): ~18 с/заливка,
~60 мс/юнит — накладные расходы на прогон, а не геометрия (потоки PGG мелкие
юниты не ускоряют). Параллельность юнитов и кэш F8 — после D1.
