# Delve: геометрические проверки F11 v1 (D1.4)

`src/libs/delve_check`: 6 проверок собранного уровня (IR + `FillResult`) —
сигналы R-A1/R-A9 до локальной сетки. Тесты: `delve_check_test` (7 шт.).

## Проверки

| Проверка | Вход | Сигнал |
|---|---|---|
| `passage` | IR | чистый проём двери: ширина ≥ 0.76, высота ≥ 2.0, проём строго внутри стены (`int`, без толеранса) |
| `opening_voids` | IR + собранный меш | в проёме выше пола (`y ≥ 0`) только запчасти типа `0` (`@style==0`), мусора нет |
| `transitions` | IR + юниты | зона шва 2×`clearance` покрыта элементами обоих соседних стилей (зазор/нахлёст 1e-3) |
| `anchors` | IR + `FillResult` | по якорю `light` на лампу, `spawn` на комнату `kind==spawn` |
| `spans` | IR (+ styles) | тела колинеарных стен не пересекаются, пересечения и T-стыки сидят на узлах, облицовки комнаты не пересекаются, облицовки вне столбов |
| `elements` | меш + `@style` | ≤ 100k элементов, площадь чётких дублей (`@style` равны) < 1e-6 м² |

`check_level` гонит все шесть; диагнозы `CheckDiag{check, unit, detail}` с
капом 10 на проверку. Все объёмы — по граням с учётом `@style` (curved-грани
аппроксимируются хордами, как в PGG `area`).

## Элемент облицовки и `@face` (инвариант ассетов)

Грани одного ряда копланарны, а `box()` индексирован (8 углов) и `merge`
не сваривает — DSU сливает соседние грани (общее ребро = 2 общих индекса
точек), только если обе без `@face` или значения равны (плюс водораздел
по `@zone` и `@style`: индекс +1 на границу, чтобы 0 означал «нет зоны»). Кромочные ряды из `@face`-ассетов рвутся на
блоки ≤ 1 м — это тоже границы зон стыковки, не артефакт проверки.

Переходы проверяются на швах, тоже обрезанных по `@face`-границам:
сегмент шва — это пересечение геометрического отрезка зоны стыковки
с элементом облицовки, а не отрезок целиком. Хвост «доски» за швом
(кромочный ряд длиннее зоны) — легален.

## Пустоты проёмов и полы

Полы (стиль ≠ 0) заходят под проёмы дверей — нижняя грань пустоты `y = 0.0`,
уровень пола: плиты пола ниже не считаются мусором, а пороги/косяки
(`@style == 0`) проходят как запчасти. Декор с ненулевым стилем внутри
пустоты — диагноз.

## Спаны: аналитика, не меш

Стены `FillResult`-меша упрощены до оболочек, поэтому пересечения стен
проверяются аналитически по IR (целочисленная планиметрия по сегментам
осей и толщинам): колинеарные тела не пересекаются, торец стены строго
внутри чужого пролёта обязан стоять на узле. Облицовки — попарно в комнате
по диапазонам проекций на обходе: пересечение диапазонов с разной
нормалью/стороной — диагноз (T-стыки узлов вырождены и не считаются).

## Саботажные фикстуры (тесты)

`src/tests/data/fill/*_v1.pgg` — копии ассетов v1 с выключенной логикой
зон/проёмов (`*_nocuts`, `*_nozones`); слоты переопределены через
`p.asset_roots = {"src/tests/data", "assets"}`. Сценарии
`delve_check_test`: заросший проём (`VoidsReject`), облицовка без зон
на стыке (`TransitionsReject`: стена + угол + штраба), пересекающиеся
стены (`SpansReject`), узкий/низкий/вылезающий проём (`PassageRejects`).

## Краска швов D1.5 (`TransitionPaintStoneBrick`)

Угловая сцена (зал stone + коридор brick) заливается в 4 конфигах
(встык/штраба × угол/стена): `check_level` обязан проходить везде, а каждая
грань твёрдо внутри шва — нести краску узора (зеркало `patterns.pgg`
`zone_side` в тесте). Запасы — чуть внутри полудлины элемента (целое правило:
сохранённый элемент не пересекает границ краски): у T-стыков куски
на облицовках — 0.2 м и пусты, середина шва проверяется на T-грани узла
(элементы 0.3 м без разбежки, столбы и тылы отсекаются по `d = thick/2`).

## Замер N5 (слоты §0)

`PassFrozen`: уровень frosted `tutorial_corridors` (17 комнат, ~280 юнитов,
~1.5M граней): ~95 с/проверка в Debug — доминирует `elements` (DSU по
граням + сравнение дублей). Порог дублей 1e-6 м² при координатах ~20 м:
f32-шум касаний даёт вклады ~1e-8 и не срабатывает.
