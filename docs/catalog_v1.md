# Delve: каталог шаблонов v1 (D2, F2)

`src/libs/delve_layout`: декларации проекта v1 → шаблоны edgar
(`RoomTemplateGrid2D`) + описания комнат (`RoomDescriptionGrid2D`).

## Параметрические шаблоны (R-C2)

- Коридоры: `width × len` для каждой длины из диапазона, имена
  `corridor_<w>x<len>`, роль `corridor`.
- Прямоугольники: `w × h` на полном произведении диапазонов, имена
  `rect_<w>x<h>`, роли — сужение `rooms_rect.roles` (пересечение с
  некорридорными ролями графа) либо все некорридорные роли графа.
  Пустое пересечение = набор не порождается (счётчик F1 считает так же).
- Правило дверей — простое проектное (`door_length`,
  `door_corner_distance`); трансформации — 4 поворота (явно: пустой
  список в порте означает только identity).

## Явные шаблоны (R-C1, R-C4)

Контур переводится как есть (обход нормализуется: конструктор
`PolygonGrid2D` принимает только `area2 < 0`, остальное разворачивается
с сохранением первой точки). Двери: проектное правило, переопределение
`length`/`corner_distance` либо ручные отрезки (`ManualDoorModeGrid2D`,
сокеты `null` = совместимы; тип двери идёт из ребра графа, project_v1).
Трансформации — объявленные; дефолт — 4 поворота; явный пустой список —
только identity. Имя, столкнувшееся с параметрическим, — ошибка сборки
каталога (переименовать явный шаблон).

## Диагностика (R-C2)

`CatalogStats`: число шаблонов (коридоры + прямоугольники + явные) и
число инстансов (шаблон × трансформации после слияния симметричных,
считает edgar) — оценка цены раскладки. Порядок детерминирован:
коридоры, прямоугольники, явные (внутри — порядок объявления).

## Описания комнат

На комнату графа: флаг коридора + копии шаблонов, в чьих ролях есть её
роль. Пустой набор невозможен после R-G3 (иначе внутренняя ошибка).
Повторы шаблонов порт не ограничивает (поле `repeat_mode` нигде не
читается), каталог из единиц шаблонов годен на любое число комнат.
Импорт `Rooms/*.yml` (R-C3, «желательно») в v1 не входит.
